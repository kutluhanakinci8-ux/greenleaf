# Masaüstü çalışma modeli

- **Uygulama:** Node `server.mjs` + statik `dist/`
- **Veri:** `MARKET_POS_DATA_DIR` (ör. `%ProgramData%\GreenleafPOS\data`)
- **Port:** varsayılan `5190`, yalnızca `127.0.0.1`
- **Ortam:** `GREENLEAF_DESKTOP=1` — bulut posta/platform özellikleri devre dışı bırakılabilir

Güncelleme: uygulama dosyaları değişir; veri klasörü korunur.
